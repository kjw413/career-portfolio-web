# 프로젝트 이미지 폴더

이 폴더에 넣은 이미지는 프로젝트 마크다운에서 `/projects/파일명` 경로로 참조합니다.
(`/career-portfolio-web` 접두사는 빌드할 때 자동으로 붙으므로 적지 마세요.)

## 넣는 방법

GitHub 저장소의 이 폴더에서 **Add file → Upload files**로 올린 뒤,
`content/projects/해당프로젝트.md` 상단에 아래처럼 적습니다.

### 대표 이미지 (카드 썸네일 + 상세 페이지 상단)

```yaml
cover:
  src: "/projects/bems-dashboard.png"
  caption: "대시보드 — 이상감지 배너와 7일 원단위 추이"
```

### 스크린샷·GIF 갤러리 (상세 페이지 하단)

```yaml
gallery:
  - src: "/projects/bems-prediction.png"
    caption: "AI 예측 — 실측과 P05~P95 구간 비교"
  - src: "/projects/rpa-run.gif"
    caption: "3종 수집이 순차 실행되는 과정 (18초)"
  - src: "/projects/todo-app.png"
    caption: "긴급도 색상이 적용된 목록"
    tall: true   # 세로로 긴 캡처는 원본 비율 유지
```

본문 안에서 마크다운 문법으로도 쓸 수 있습니다.

```markdown
![예측 결과 화면](/projects/bems-prediction.png)
```

## 아직 올리지 않은 이미지는 어떻게 되나

**깨진 이미지로 보이지 않고 조용히 생략됩니다.** 마크다운에 파일명을 먼저 적어두고
나중에 올려도 되고, 올리는 순간 다음 배포에서 자동으로 나타납니다.

`cover`로 지정한 파일이 아직 없으면 `gallery`의 첫 자료가 대표 이미지 자리를
대신 채웁니다. 실제 파일을 올리면 그것이 대표 이미지가 됩니다.

## 권장 사양

| 용도 | 크기 | 형식 | 비고 |
|---|---|---|---|
| 대표 이미지 | 가로 1600px 내외 | PNG / SVG | 카드에서 16:7로 잘리므로 중요한 내용은 위쪽에 |
| 상세 스크린샷 | 가로 1600px 내외 | PNG | 1MB 이하 권장 |
| 실행 GIF | 가로 1000px 내외 | GIF | 15~20초, 5MB 이하 |
| 다이어그램 | 자유 | SVG | 확대해도 깨지지 않고 용량이 작음 |

전체 페이지 용량이 커지면 로딩이 느려집니다. 스크린샷은 올리기 전에
[squoosh.app](https://squoosh.app) 같은 도구로 한 번 압축하는 것을 권장합니다.

## ⚠️ 회사 데이터 주의

이 사이트는 **공개 웹사이트**입니다. 사내 시스템 화면을 그대로 올리면
회사 데이터가 외부에 공개됩니다. 반드시 아래 중 하나로 처리하세요.

- **더미 데이터로 다시 실행**한 화면을 캡처 (가장 안전 — 권장)
- 공장명·수치·금액·계정명을 가리거나 치환 후 캡처
- 형태만 보여주는 다이어그램으로 대체

캡처에 남기 쉬운 것들: 창 제목표시줄의 사내 서버 주소, 브라우저 탭·북마크,
작업표시줄 프로그램, 파일 경로, 사번·이름, 거래처명.
