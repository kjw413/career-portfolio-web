## 개요

5개 공장의 에너지·생산 데이터를 하나로 통합하고, 조회–예측–진단–보고로 이어지는
업무 흐름을 하나의 웹 서비스로 구현한 프로젝트입니다. 사내 AI 전문가 육성과정(AI ELITE)에서
제조 데이터 기반 서비스로 완성했습니다.

## 수행 과정

- 5개 공장의 에너지·생산 데이터를 수집·정제해 MySQL 기반으로 통합
- 에너지 사용량 예측 모델과 이상 진단 로직 구현
- LangChain 기반 LLM을 연결해 분석 결과를 보고 형태로 자동 생성
- Streamlit 웹 인터페이스로 조회–예측–진단–보고 워크플로 구성

## 성과

- 에너지 예측 MAPE 3–5% 달성
- 예측 모델·LLM·웹 인터페이스를 하나의 실무 워크플로로 연결
